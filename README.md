# 猜猜谁是“乱”？

这是一个在我梦里出现的游戏，因为觉得很有意思，就把它实现了放在 GitHub 上，大家可以一起来玩玩。

这是一个基于排除法的逻辑推理小游戏。玩家需要根据角色提供的信息，判断他们的真实身份。

## 游戏规则

- 有三个角色，分别是“温”“顺”“乱”，随机分配给1、2、3号。
- 每个角色都不会说出自己的真实身份。
- 三个角色的真实身份互不重复。
- 玩家可以根据第一次发言直接回答，也可以使用一次追问机会。
- 被追问的角色必须说出与第一次不同的另一个假身份。
- 只有能够通过已有线索确定答案，才算推理成功。碰巧猜对不算通过。

## 难度等级

**Level 1：初级**

找出谁是“乱”。题目不需要追问就能得出确定答案。

**Level 2：中级**

随机指定寻找“温”“顺”“乱”中的一个角色。玩家需要判断是否使用追问机会，以及追问谁。

**Level 3：高级**

还原全部三个角色的真实身份。最多可以追问一次，必须得到能够由线索唯一确定的答案。

成功完成当前等级后，自动进入下一个等级。

## 运行方法

需要 Python 3，无须安装额外依赖库。

在终端执行：

`python main.py`
